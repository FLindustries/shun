Does Shun still work with YouTube?

YouTube changes its pages often, and an extension like Shun can break when it does. This page says when Shun was last checked on the real youtube.com, how, what worked, what didn't, and what changed in recent versions.

Last verified: November 23, 2026, with Shun 1.4.4. Written by the developer of Shun.

On this page

  1. How it was checked
  2. Channel blocking
  3. Keywords and topics
  4. Shorts, comments and tools
  5. Known limits
  6. Recent versions

Short answerYes, as of November 23, 2026. Channel, keyword and topic blocking, Hide Shorts, Hide comments and the tools inside YouTube were checked on youtube.com that day, and most of what this site says held up. Two gaps found in that first check were fixed in 1.4.4: a channel block now hides that channel's Shorts in Shorts shelves in search results, and a renamed channel is blocked on its own page by its @handle. Collab videos are now hidden when any channel named on them is blocked. Japanese, Chinese and Korean keywords now match inside a title, but that is unit-tested only, not re-checked on live YouTube. Some things still hold only in part; see Known limits.

How it was checked

  • The real thing. Shun's extension files, loaded the way they ship, in Chromium on a computer, driven by test scripts, on the real youtube.com.
  • Signed out. The test browser never signs in to YouTube, and its cookie banner is answered with “Reject all”.
  • Before and after. Each check looks at the same page before and after a block, without reloading it, and counts what is shown and hidden. A screenshot and the raw counts are kept for each check.
  • Version. Shun 1.4.4, on the Chrome Web Store since November 24, 2026. The rows for Shorts shelves, collabs, a renamed channel's own page and importing a list were re-run on 1.4.4 on November 23, 2026. Other rows were checked the same day on the filtering code of 1.4.2 and 1.4.3, which 1.4.4 changes only where this page says so. If your version is older than 1.4.4, some results here may differ. To see your version, open chrome://extensions.
  • What couldn't be checked live. Signed out, YouTube shows no Home feed and no Subscriptions feed, and its 3-dot menu has no “Don't recommend channel”. Those parts were checked in Shun's code only, and are marked “Code only” below.

Known limits

  • Shorts shelves and channel blocks. A Short inside a Shorts shelf doesn't show which channel made it, so since 1.4.4 Shun asks youtube.com (the Short's ID only) and hides it when the answer arrives. Checked in search results only. A Short whose owner can't be looked up (for instance embedding is off) stays visible; Hide Shorts, a keyword or a topic still hide it.
  • Japanese, Chinese and Korean titles. A word matches anywhere inside a title, so a short word (even a single character) can also hide titles where it is part of a longer word. Unit-tested only, not re-checked on live YouTube.
  • @handle. Used where YouTube shows it: next to a video in search results and playlists, and on a channel's own page. Up next shows no handle, so it matches by name only.
  • Collabs. A collab card names only some channels (“KSI and 2 more”). The ones it doesn't name can't be matched.
  • Tech and Sports. These topics let almost no history or documentary titles through, unlike Gaming, AI Hype and News.
  • “Watch just now”. Shun asks before playing a video with a blocked word or topic only when that video slips past the filter. In the check, the matching video was hidden before it could be clicked, so the site no longer lists it as a feature.
  • Shorts previews in search. With Hide Shorts on, the floating preview YouTube shows when you hover a Shorts result could still appear.
  • Computer only. Shun works on youtube.com in Chrome on a computer. It can't change the YouTube app on phones, tablets or TVs.

Recent versions

1.4.7 (November 25, 2026)

  • Strict Mode asks for the password in Shun's own dialog; the password is hidden while you type.
  • Removing a channel from the Blocked list removes the one you clicked, even if you blocked another channel in a YouTube tab meanwhile.
  • An empty Blocked list explains how to block a channel and how to import a list.
  • Messages inside YouTube are clearer and translated into Italian.
  • No change to what gets blocked.

1.4.6 (November 25, 2026)

  • Shun's buttons, menu items and messages inside YouTube now follow YouTube's own look in light and dark theme.
  • Popup and Settings: switches work with the keyboard and screen readers, focus is visible, and text is easier to read in dark mode.
  • No change to what gets blocked.

1.4.5 (November 25, 2026)

  • Pasted lists can use site-relative links (/@name, /channel/UC…), as some shared blocklists write them.
  • On Microsoft Edge, the rating prompt opens the Edge Add-ons listing.

1.4.4 (Chrome Web Store, November 24, 2026)

  • Blocking a channel now also hides its Shorts inside Shorts shelves in search results.
  • Collab videos are hidden when any channel named on them is blocked, and the 3-dot menu offers one Block item per channel.
  • A renamed channel is blocked on its own page by its @handle.
  • Undo for a few seconds after blocking a channel, and Manage subscription for Pro users.
  • Free import from BlockTube, Channel Blocker and pasted lists.
  • Japanese, Chinese and Korean keywords match anywhere inside a title (unit-tested only).

1.4.3 (November 23, 2026)

  • New store name, “Shun for YouTube: Block Channels, Keywords & Topics”, and a description that starts with channel blocking.
  • The plan picker shows the 30-day money-back guarantee.
  • Blocking works as in 1.4.2.

1.4.2 (built November 14, 2026; replaced by 1.4.3 before release)

  • CleanFeed is now called Shun: same extension, same lists. Existing users see a one-time notice, and the quick-add button is now Shun+.
  • Keyword and topic blocking check the video title only, not the description.
  • Adding your own words to a topic is Pro for new installs. Every earlier install keeps it free.
  • Blocking a topic now says “Blocked topic”, not “Blocked keyword”.
  • Strict Mode says plainly that it can't stop someone from turning off or removing the extension.
  • The rating prompt offers everyone the same choices: rate, send feedback, or later.
  • Backups saved by CleanFeed still import.

1.4.1 (November 2, 2026)

  • After some real use, the popup asks once what you think of Shun.
  • Removing Shun opens a short page where you can tell us why, by email if you want.

1.4.0 (October 12, 2026)

  • Pro plans (Monthly, Yearly, Lifetime) with prices shown in the extension.
  • Shun starts working in YouTube tabs that were already open when you install or update it.
  • Shorts are filtered in search results and in the Shorts player.
  • Keywords match words with accents and non-Latin letters, such as Cyrillic.
  • Strict Mode asks for the password before every change that loosens your filters.
  • Auto-tag counts each video once, and Untag sticks.
